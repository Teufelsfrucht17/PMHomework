FAIR COMPARISON FRAMEWORK
1. Freeze the Q1 targets estimated through June 2014; first earn July 2014 returns.
   Use the same July-2014 to December-2024 monthly observations for all eligible portfolios.
   A common return period alone does not remove future information from weight construction.
2. Hold the long-only, fully invested constraints, zero risk-free rate, and zero costs fixed.
   Objectives differ by design: tangency uses means; minimum variance/ERC use covariance;
   inverse volatility ignores correlations; most-diversified uses volatility and covariance.
   Their identical estimation dates make these rule differences comparable.
3. Monthly rebalancing means restoring the SAME frozen target weights before each month's return.
   It does not mean re-estimating parameters each month. Buy-and-hold would let weights drift;
   rolling re-estimation would be a new strategy requiring a separately specified information rule.
4. Alphabetical/group rules may join only if the supplied universe, names and groups are
   treated as known at June 2014; their metadata dates are unverified, not demonstrably future-free.
5. Professor correction: P1 uses Jan-2004 shares and prices; P2 uses those same
   Jan-2004 shares with Jun-2014 prices. Neither uses December-2024 share proxies.
   Both can join the July-2014 comparison, conditional on availability of the supplied
   universe/shares. Supplied price/share inputs are used as directed. P2 deliberately fixes
   shares at January 2004; it is not a claim about actual June-2014 market capitalizations.
   P1's month-end January prices are not available on January 1, 2004.
6. DJIA is a separate price-weighted index series, excluded from the 30 stock vectors.
   Comparing its price changes on identical dates can be informative, but it has a different
   weighting/membership methodology. Professor Q4 requires retaining its original row dates;
   Q5 requires comparing its supplied-price returns with the portfolios on those same dates.
